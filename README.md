# evil-sdk

The AWS SDK for .NET's evil twin: C# clients for AWS services, generated by
[NSmithy](https://github.com/thomaslaich/smithy-dotnet) from the official
[AWS Smithy models](https://github.com/aws/api-models-aws).

This is a side project to battle-test NSmithy against the full AWS catalog. It
is not affiliated with or supported by AWS; for production use, see the
[AWS SDK for .NET](https://github.com/aws/aws-sdk-net).

## Layout

- `aws-models/`: the AWS models, as a shallow git submodule.
- `services/<id>/`: checked-in generated clients for the services in
  `services.txt`. Each one is a plain C# project that references the NSmithy
  runtime packages; consumers need no Java or Smithy CLI.
- `scripts/nsaws.py`: runs the Smithy CLI with NSmithy's `csharp-codegen`
  plugin, writes each service project, and sweeps the catalog.
- `reports/`: the latest sweep result (`sweep.md`, `sweep.json`).

## Usage

Requires .NET 10, Java 17+, Python 3.11+, the Smithy CLI 1.74.1 on `PATH`
(or `SMITHY=/path/to/smithy`), and [`just`](https://github.com/casey/just).

```sh
git submodule update --init --depth 1
just generate          # regenerate services/ from services.txt
just generate s3 ec2   # regenerate specific services
just build             # compile the checked-in services
just sweep             # generate and compile all ~436 services into .sweep/
just sweep dynamodb    # sweep specific services
```

The NSmithy version is set by `NSmithyVersion` in `Directory.Build.props` and
is used for both the codegen JAR (Maven Central) and the runtime packages
(nuget.org).

To test an unreleased NSmithy, run `just codegen pack` in a smithy-dotnet
checkout and point `NSMITHY_LOCAL` at it:

```sh
NSMITHY_LOCAL=../smithy-dotnet just sweep
```

## Sweep stages

| Stage | Meaning |
| --- | --- |
| `codegen` | `smithy build` failed or produced no C# |
| `compile` | the generated project does not compile |
| `ok` | the generated project compiles |

Compiling is the first gate only. Endpoint rules, waiters, SigV4a, and
service customizations are not covered yet.
